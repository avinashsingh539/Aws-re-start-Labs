# AWS Academy Labs

This repository contains my hands-on AWS Academy labs, Linux command-line exercises, system administration tasks, and AWS practical implementations.

## How to Use This Repository

Each lab has its own README file containing the instructions and steps required to complete the practical.

1. **Choose a lab** you want to learn or practice.
2. **Open its README file** to view the objective, requirements, commands, and step-by-step instructions.
3. **Follow the steps in order** and perform the practical in the appropriate AWS environment or Linux terminal.
4. **Verify the results** using the expected outputs or verification steps mentioned in the README.
5. **Practice the commands yourself** to understand the concepts instead of simply copying them.

## Important Notes

- Some labs require access to the AWS Academy Learner Lab or Vocareum environment.
- AWS services and resources may require an active lab session and appropriate permissions.
- Follow the instructions carefully, especially when working with AWS resources, Linux permissions, and system administration commands.
- Avoid committing AWS credentials, access keys, private keys, or other sensitive information to this repository.
- Clean up AWS resources after completing a lab when instructed to avoid unnecessary charges.
- The results may different ! always check requirement before submitting .

## Purpose

The goal of this repository is to document practical learning, strengthen Linux and AWS skills, and maintain a reference for revising commands, concepts, and lab procedures.
